# FreeAppSource

Free, open-source **React Native** mobile apps built with **Expo** and **Expo Router**. Each app is based on a free UI design shared by its designer on [Sketch App Sources](https://www.sketchappsources.com/category/mobile.html), the [Figma Community](https://www.figma.com/community), or other sources where the design is free or MIT-licensed. Every design is credited to its designer in the app's README.
