# FreeAppSource

Free, open-source **React Native** mobile apps built with **Expo** and **Expo Router**, each based on a free UI design shared by its designer on [Sketch App Sources](https://www.sketchappsources.com/category/mobile.html).

## 👨‍💻 Developer

All apps are developed by **[Suresh Kumar Meesala](https://github.com/SureshKumarMeesala)** ([@SureshKumarMeesala](https://github.com/SureshKumarMeesala)).
